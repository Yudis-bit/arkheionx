# Arkheionx v7.0.0 — Scope-Aware Orchestration

V7 adds scope-aware orchestration: scope map, review lanes, scope tasks, evidence
judging, report filtering, and complete scope packs for local/static,
human-reviewed smart-contract security research.

**Release metadata finalized locally; pending founder push/tag/GitHub release/site
deploy.** The package version is `7.0.0`; the last published tag remains `v4.0.0`.

## What's new

- `arkheionx scope-map` — parse a contest/audit/program scope note into structured
  review rules.
- `arkheionx scope-lanes` — generate scope-aware review lanes from repository
  surfaces plus scope rules.
- `arkheionx scope-tasks` — turn lanes into precise, bounded, evidence-oriented
  tasks for a human reviewer or a model-agnostic AI agent.
- `arkheionx scope-pack` — bundle a complete local scope-aware research pack.
- `arkheionx evidence-judge` — judge whether local tests/evidence prove the
  intended task on a transparent rubric.
- `arkheionx report-filter` — classify report candidates against scope rules before
  submission, with a human pre-submission checklist.

V7 builds directly on the stable v4 `review-map` workflow (and the focused
`value-paths`, `assumptions`, `test-gap-map`, `proof-plan` views), the v5
blind-spot layer, and the v6 evidence-graph layer. It removes nothing.

## Approved positioning

V7 turns audit scope into review lanes, task packs, evidence requirements, and
report filters so AI-assisted security review starts from rules and evidence
instead of vague prompts.

## Known limitations

- Local/static and heuristic.
- No bug prediction and no severity.
- No exploit automation.
- No live-chain or RPC.
- No auto-submission.
- Human review is required for every conclusion.
- Private scope files are local only and must not be committed.

## Safety

A scope map, review lane, or scope task is a planning artifact, not a finding.
Evidence quality is not vulnerability validity. Candidate-with-evidence is not a
confirmed vulnerability. A report candidate is not final triage. Arkheionx does not
confirm vulnerabilities, assign severity, prove protocol safety, or replace an
audit.
