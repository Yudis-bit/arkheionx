# Arkheionx v2.7.0 — Guided Demo Fixtures & First Real Workflow

Arkheionx v2.7.0 makes the first real workflow easy to experience: copy a safe
local demo fixture and run the full loop. The v2.6.0 install/update lifecycle
and the core evidence workflow are unchanged.

> Release date: 2026-05-31. Package version `2.7.0`. The `STABLE_RELEASE`
> pointer remains `v2.6.0` until this release is published, then moves to
> `v2.7.0` in post-release cleanup. Not published to PyPI. Not a formal audit;
> no bounty or severity guarantee.

## Summary

`arkheionx demo` lists, shows, and copies a safe local fixture so a new
developer can run open → hunt → prove → trace → evidence → report and see what
is proven and what is not — with no RPC, no secrets, and no mainnet.

## Demo command

```sh
arkheionx demo --list
arkheionx demo --show oracle-staking
arkheionx demo --commands oracle-staking
arkheionx demo --copy oracle-staking ./arkheionx-demo
```

`--copy` copies source entries only (`README.md`, `foundry.toml`, `src/`,
`test/`), refuses a non-empty destination unless `--force`, and never writes
outside the destination.

## Demo fixture registry

A small registry (`arkheionx/demo/`) defines safe, local-only demos. The
primary demo is `oracle-staking`, mapped to the existing
`examples/oracle-staking-fixture` Foundry project (recommended target
`OracleRewardFixture.stake`).

## oracle-staking fixture

A toy oracle/staking fixture for demonstrating the workflow. It is not a real
protocol and not a vulnerability report. It contains no RPC URLs, private keys,
secrets, or live addresses.

## First workflow docs

`docs/DEMO_WORKFLOW.md` walks through install/verify, list/copy, doctor,
open/map/flow/hunt, optional Foundry prove/trace/evidence/report,
evidence-status/validate-artifacts, cleanup, and an explicit
"what is proven / what is not proven" section.

## Foundry-optional behavior

Without Foundry, the demo runs in `HEURISTIC` mode (`open`/`hunt` exit `1`).
With `forge`, `prove --run` can reach `COMPILER_CONFIRMED` /
`EXECUTION_CONFIRMED` and the evidence package can reach `EVIDENCE_READY`.
`arkheionx demo --commands` prints both paths.

## Safety boundaries

- Local/static only; no RPC; no private keys; no secrets; no mainnet.
- No live-chain instructions, no auto-submission, no bounty framing, no final
  severity. Human review is always required.
- No PyPI, Homebrew, standalone binaries, or domain installer.

## Validation

- `python3 -m unittest discover -s tests -p "test_*.py"` — full suite.
- `make validate` — docs links, version consistency, safety wording.
- `sh -n install.sh`, `sh -n uninstall.sh`, `sh -n arkup`.
- Demo smoke: `demo --list/--show/--commands`, safe `--copy`, copied-demo open.

## Known limitations

- Demo fixtures ship with the source checkout / editable install; `--copy`
  resolves them from the repository (not bundled as package data).
- `arkheionx demo --run` is intentionally not implemented; use `--commands`.
- Toy fixture only; not a real protocol, vulnerability, or severity claim.
