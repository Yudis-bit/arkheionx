# Arkheionx v2.8.0 — Package Data & Distribution Hardening

Arkheionx v2.8.0 makes the guided demo work reliably from an installed package
by bundling demo fixtures as package data. The v2.7.0 demo workflow and the
core evidence workflow are unchanged.

> Release date: 2026-05-31. Package version `2.8.0`. The `STABLE_RELEASE`
> pointer remains `v2.7.0` until this release is published, then moves to
> `v2.8.0` in post-release cleanup. Not published to PyPI. Not a formal audit;
> no bounty or severity guarantee.

## Summary

`arkheionx demo --copy oracle-staking <dest>` now works from an installed
package context, not only from the source repository checkout — a step toward a
more production-ready CLI package.

## Highlights

- Demo fixtures bundled as package data (`arkheionx/demo/fixtures/`).
- `importlib.resources` resolution with a source-checkout fallback.
- `demo --show`/`--copy` report the resolved source.
- Non-editable venv install can run `demo --copy` with no checkout present.

## What changed since v2.7.0

- Added bundled fixture package data and `pyproject` package-data config.
- Reworked demo resolution to prefer the bundled resource.
- Added `docs/PACKAGE_DATA.md` and `tests/test_package_data.py`.
- Version metadata finalized to `2.8.0`.

## Package-data fixture bundling

Under `arkheionx/demo/fixtures/oracle-staking/`: `README.md`, `foundry.toml`,
`src/OracleRewardFixture.sol`, `test/OracleRewardFixture.t.sol`. Included via
`[tool.setuptools.package-data]` for `*.md`, `*.toml`, `*.sol` only — no
generated directories, secrets, RPC URLs, or private keys.

## demo --copy from an installed package

```sh
python3 -m venv /tmp/ark-venv
/tmp/ark-venv/bin/pip install .
/tmp/ark-venv/bin/arkheionx demo --copy oracle-staking /tmp/demo
```

The copy keeps the source allowlist (`README.md`, `foundry.toml`, `src/`,
`test/`), refuses a non-empty destination unless `--force`, and never writes
outside the destination.

## Resource resolution

1. Bundled package fixture — `importlib.resources.files("arkheionx.demo.fixtures")`.
2. Source-checkout fallback — `examples/oracle-staking-fixture`.
3. Otherwise: *"demo fixture resource not found; reinstall Arkheionx or use a
   source checkout."*

`arkheionx demo --show oracle-staking` reports `Source: bundled package fixture`
or `Source: source checkout fixture`.

## Package-data tests

`tests/test_package_data.py` checks the resource exists and contains the
expected source files, excludes generated artifacts, copies from a non-repo
working directory, and (when feasible) installs into a temporary virtual
environment to prove the fixture ships in a built wheel.

## Docs added

- `docs/PACKAGE_DATA.md`, plus updates to demo/CLI/troubleshooting/roadmap docs.

## Safety boundaries

- Local-only; no RPC; no private keys; no secrets; no mainnet; no live-chain
  instructions. Bundled fixture is a toy, not a real protocol or a vulnerability
  report. No PyPI, Homebrew, standalone binary, or domain installer.

## Validation

- `python3 -m unittest discover -s tests -p "test_*.py"` — full suite.
- `make validate` — docs links, version consistency, safety wording.
- Package resource smoke + non-editable venv install + `demo --copy` from a
  non-repo directory.

## Known limitations

- Only the `oracle-staking` demo is bundled.
- No PyPI/Homebrew/binary/domain installer.
- `examples/oracle-staking-fixture` remains for the source checkout and tests.

## Upgrade

```sh
git pull
sh arkup --update          # or: pip install -e .
arkheionx demo --copy oracle-staking ./arkheionx-demo
```
