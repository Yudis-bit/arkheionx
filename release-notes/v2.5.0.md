# Arkheionx v2.5.0 — Installer & Onboarding

Arkheionx v2.5.0 focuses on the first-user experience: a clean install path, a
clean uninstall path, clearer doctor output, and honest onboarding docs. The
v2.4.0 evidence workflow is unchanged.

> Status: in development (`2.5.0-dev`, package `2.5.0.dev0`). Stable release
> remains `v2.4.0`. Not published to PyPI. Not a formal audit; no bounty or
> severity guarantee.

## Summary

Install → verify → doctor → first run, without root, without editing your shell
profile, and without any RPC, private keys, or secrets.

## Highlights

- `install.sh` — safe local installer (pipx or isolated venv).
- `uninstall.sh` — safe, conservative removal of only Arkheionx-managed paths.
- `arkheionx doctor --install` — focused install-health view.
- New onboarding docs and a no-RPC 5-minute demo.

## install.sh

- POSIX `sh`, `set -eu`, `curl`-friendly, lintable with `sh -n`.
- Detects OS (Linux/macOS; unsupported Windows shells exit with guidance) and
  Python 3.11+.
- Prefers `pipx`; falls back to `~/.arkheionx/venv` plus a wrapper at
  `~/.arkheionx/bin/arkheionx`.
- `--help`, `--dry-run`, `--method auto|pipx|venv`, `--local`, and
  `ARKHEIONX_*` environment variables (`REPO_URL`, `REF`, `INSTALL_DIR`,
  `BIN_DIR`, `INSTALL_METHOD`, `LOCAL_PATH`, `YES`, `DRY_RUN`).
- Prints exact next steps (PATH line, `arkheionx version`, `doctor`, `open .`).
- No root, no shell-profile edits, no secrets, no RPC, no live-chain calls.

## uninstall.sh

- Removes only `~/.arkheionx/bin/arkheionx`, `~/.arkheionx/venv`, and empty
  managed directories.
- Refuses to operate on a non-`.arkheionx` install dir (exit `2`).
- `--dry-run`, `ARKHEIONX_YES`, and `pipx uninstall arkheionx` guidance
  (optionally run with `ARKHEIONX_PIPX_UNINSTALL=1`).
- Never deletes repo checkouts, reports, or per-project `.arkheionx/` artifacts.

## doctor / onboarding improvements

- `arkheionx doctor --install` reports the resolved command path, Python
  executable, package import/version, optional Foundry status, and a PATH hint.
- Default `arkheionx doctor` output is unchanged.

## Docs added

- `docs/INSTALLER.md`, `docs/UNINSTALL.md`, `docs/ONBOARDING.md`,
  `docs/TROUBLESHOOTING.md`.
- Updated `docs/INSTALLATION.md`, `docs/TRY_IN_5_MINUTES.md`,
  `docs/CLI_REFERENCE.md`, `docs/ROADMAP.md`, `docs/RELEASE_CHECKLIST.md`.

## Safety boundaries

- Local/static analysis only; no RPC by default; no live-chain mutation.
- No root, no shell-profile edits, no secrets, no private keys.
- Not published to PyPI. Not a formal audit; no severity guarantee.

## Validation

- `python3 -m unittest discover -s tests -p "test_*.py"` — full suite.
- `make validate` — including docs links, version consistency, and safety
  wording checks.
- `sh -n install.sh`, `sh -n uninstall.sh`.
- CLI smoke: `arkheionx --help`, `version`, `doctor`, `doctor --install`.
- Local install/uninstall cycle verified with `ARKHEIONX_LOCAL_PATH`.

## Known limitations

- `arkup` version manager is deferred to v2.6.0 or later.
- No domain installer, standalone binary, or Homebrew tap.
- The `curl | sh` one-liner is documented as available only once v2.5.0 is
  finalized; install from a local checkout until then.

## Upgrade

```sh
git pull
sh install.sh            # or: python3 -m pip install -e .
arkheionx version
arkheionx doctor --install
```
