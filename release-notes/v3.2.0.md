## Summary

v3.2.0 makes Arkheionx easier to understand and use as a local-first pre-audit readiness workflow. This is the Developer-Native Review Map and Local Artifact Foundation release: it stabilizes the developer-native `review-map` experience, adds Test Gap Map artifacts derived from the existing review map, clarifies the product direction toward a Protocol Security Control Plane, and keeps the safety boundaries intact.

## What Shipped

This section describes the v3.2.0 release contents. Post-release stable-pointer cleanup remains a separate task after the release tag.

### Developer-Native Review Map

- Improved `arkheionx review-map` human output with a clearer banner, static/local mode line, summary sections, next-step guidance, and boundary reminder.
- Progress reporting is honest: no fake percentages, no artificial sleeps, and phase details are based on completed work.
- `review-map --json` remains pure machine-readable JSON with no human UI chrome.
- `review-map --no-write` remains safe and does not create `.arkheionx/out/review-map/`.
- The default behavior remains local/static review guidance unless the user explicitly runs proof or evidence workflows.

### Terminal UI Foundation

- Added a reusable dependency-free `TerminalUI` foundation for human CLI output.
- Extended the `arkheionx open` human presentation to use the same TerminalUI style.
- Color and animation are guarded by TTY, CI, no-animation, quiet, and machine-readable modes.
- JSON and other machine-readable output paths are unaffected by TerminalUI formatting.

### Test Gap Map Artifacts

- `arkheionx review-map` now writes additive Test Gap Map artifacts:
  - `.arkheionx/out/review-map/test-gap-map.json`
  - `.arkheionx/out/review-map/test-gap-map.md`
- Test Gap Map data is derived from the existing review-map analysis. It does not add a new analysis engine.
- v3.2.0 does not add a first-class `arkheionx test-gap-map` command or a new `review-map` flag for this output.
- The artifacts help developers decide which tests or local proofs to write first.
- Test Gap Map priority means review order. It is not final severity, exploitability, or vulnerability confirmation.

### Documentation and Product Direction

- Refreshed the root README positioning around Arkheionx as a local-first Protocol Security Control Plane direction for DeFi protocol teams.
- Added or updated developer-facing orientation docs, including `docs/START_HERE.md`, `docs/CLI_UX.md`, `docs/ROADMAP_TO_V4.md`, and `docs/product/ARKHEIONX_PRODUCT_POSITIONING.md`.
- Added Sprint 0 architecture docs for the v4 direction.
- The Protocol Security Control Plane positioning is product direction. v3.2.0 remains a developer-native review-map and local artifact foundation release.
- Workspace baselines, diffs, sessions, reviewer notes, policy profiles, review packages, and committed workspace policy are planned v4 work, not current v3.2.0 runtime features.

### Safety and Compatibility

- Arkheionx remains local-first and static by default.
- No RPC is used by default.
- No private keys or seed phrases are required.
- No transactions are broadcast.
- No exploit automation, bounty automation, or auto-submit workflow is provided.
- Heuristic outputs are review guidance, not confirmed vulnerabilities.
- JSON and artifact compatibility are preserved for current command surfaces.
- Generated artifacts remain local, generated, gitignored by default, and not intended to be committed in v3.2.0.

## How to Try It

Basic local workflow:

```bash
arkheionx version
arkheionx open .
arkheionx review-map .
```

Demo workflow:

```bash
arkheionx demo --copy lending-vault ./arkheionx-demo
arkheionx open ./arkheionx-demo
arkheionx review-map ./arkheionx-demo
```

Optional local proof/evidence workflow:

```bash
arkheionx prove ./arkheionx-demo --target LendingVaultFixture.borrow --run
arkheionx trace ./arkheionx-demo --target LendingVaultFixture.borrow
arkheionx evidence ./arkheionx-demo --target LendingVaultFixture.borrow
arkheionx report ./arkheionx-demo --target LendingVaultFixture.borrow
arkheionx validate-artifacts ./arkheionx-demo
```

## Known Limitations

- No live-chain scanning is provided.
- No deployed-contract scanning is provided.
- No private-key workflow is provided.
- No first-class baseline, diff, session, notes, policy-profile, or package command exists yet.
- No committed workspace carve-out exists yet.
- No dedicated artifact-validation failure code exists yet.
- No `REPORT_READY` validator alias migration exists yet.
- `HUMAN_REVIEWED` is not emitted automatically.
- Human review remains required.
