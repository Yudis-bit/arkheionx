# Arkheionx v2.3.0 — Evidence & Report Package

Arkheionx closes the solo-research loop: map the protocol, rank surfaces, prove
with Foundry, summarize the trace, package the evidence, and draft a responsible
local report.

> Status: prepared locally (v2.3.0-dev). Not published to PyPI. Not a formal
> audit; no bounty or severity guarantee.

## Summary

v2.2.0 could map, rank, prove, and trace. v2.3.0 packages those results into a
structured evidence package and a responsible report draft — locally, with
honest evidence levels and no auto-submit.

## Highlights

- `arkheionx evidence` — compact, structured evidence package from proof + trace.
- `arkheionx report` — responsible local report draft (no auto-submit, no final severity).
- New `EVIDENCE_READY` level (only when execution-confirmed proof + trace exist).
- Coherent next-command chain through the whole workflow.

## New Commands

- `arkheionx evidence <repo> --target <target>` (also `--from-proof <path>`)
- `arkheionx report <repo> --target <target>` (also `--from-evidence <path>`)

## Workflow

```text
doctor → open → map → flow → hunt → prove --run → trace → evidence → report → manual review
```

```sh
arkheionx hunt . --top 5
arkheionx prove . --target Contract.function --run
arkheionx trace . --target Contract.function
arkheionx evidence . --target Contract.function
arkheionx report . --target Contract.function
```

## Evidence / Report Behavior

- `evidence` reads `proof.json` + `trace.json`, assembles `evidence.json` /
  `evidence.txt`, and assigns an honest evidence level. No proof → it prints the
  exact `prove --run` next command.
- `report` turns an evidence package into `report.md` / `report.json`. It never
  auto-submits, never claims final severity, and includes a safety notice,
  assumptions, limitations, and local-only reproduction steps.

## Safety Boundaries

- Local analysis only; no RPC, no broadcast, no private keys.
- No live-chain exploitation instructions.
- No final severity, no bounty guarantee, not a formal audit.

## Validation

- `python3 -m unittest discover -s tests -p "test_*.py"` — full suite passing.
- `make validate` — passing.
- CLI smoke — passing (heuristic flows plus an execution-confirmed Foundry
  fixture proof → trace → evidence → report).

## Known Limitations

- Evidence/report are local draft tools, not submission or grading tools.
- `EVIDENCE_READY` still requires human validation of the property under test.
- Trace parsing remains conservative; balance/state deltas are not inferred.
- Not published to PyPI in this release.
