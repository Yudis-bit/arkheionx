# Arkheionx v2.2.0 — Execution Proof & Trace Workbench

Arkheionx moves beyond installable CLI packaging into a Foundry-style local
security workbench: map the protocol, find the money, rank the surfaces, and
back findings with execution-aware proof artifacts.

> Release date: 2026-05-31. Package version `2.2.0`. Not published to PyPI.
> Not a formal audit; no bounty or severity guarantee.

## Highlights

- Terminal-first workbench commands (compact by default).
- Protocol map / money-flow / hunt workflow.
- Fully-qualified proof targets with ambiguity rejection.
- Source-kind filtering (interfaces/tests/invariants/mocks hidden by default).
- Foundry-aware proof scaffolding.
- Execution proof artifacts (`proof.json`).
- Trace summaries (`trace.json` + compact terminal view).
- Honest evidence levels.

## Evidence model

- `HEURISTIC` — static scan only.
- `COMPILER_CONFIRMED` — `forge build` passed.
- `EXECUTION_CONFIRMED` — a relevant local Foundry test actually executed.

A skipped test, a TODO scaffold, a build-only run, or a no-match run is never
EXECUTION_CONFIRMED. A passing test does not prove the absence of a bug; a
failing test does not by itself prove a vulnerability.

## Example workflow

```sh
pip install -e .
arkheionx doctor
arkheionx open .
arkheionx hunt . --top 5
arkheionx prove . --target Contract.function
arkheionx prove . --target Contract.function --run
arkheionx trace . --target Contract.function
```

## Safety boundaries

- Local analysis only.
- No live-chain testing by default.
- No broadcast, no `cast send`, no RPC required by default.
- No private keys, no exploit automation.
- Not a formal audit; no severity guarantee.

## Validation

- `make validate` — passing (editable install, console smoke, consistency gates).
- CLI smoke — passing (heuristic flows plus an execution-confirmed Foundry
  fixture proof/trace).

## Known limitations

- Static classification stays heuristic when Foundry is missing.
- Trace parsing is conservative; balance/state deltas are not inferred.
- `EXECUTION_CONFIRMED` requires an actual local Foundry test execution.
- Not published to PyPI in this release.
- Not a formal audit.
