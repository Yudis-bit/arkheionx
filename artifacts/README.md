# Artifacts Boundary

This directory is reserved for generated smoke-test and sample review artifacts.

The files under `artifacts/smoke-*` are generated outputs from local validation runs. They are useful for regression checks, documentation examples, and output-shape review, but they are not claims about live exploitable targets.

ArkheionX outputs are review context. They do not automatically confirm vulnerabilities, decide severity, prove protocol safety, or replace human review.

Most generated artifact contents are ignored by git. Keep this README as the public boundary marker.
