# ArkheionX Services

ArkheionX is local-first review tooling. This page describes optional support
boundaries for teams that want help installing, running, or interpreting the
tool on authorized repositories.

The public repository is the source of truth for current capabilities. Support
work must stay inside the same safety boundary as the tool.

## What Support Can Include

- Local setup and validation.
- Review-map and fixture-harness walkthroughs.
- Deterministic artifact review.
- Snapshot drift triage.
- Documentation of assumptions, value paths, and test gaps.
- Help preparing a local review package for human inspection.

## What Support Does Not Include

- No audit result or certification.
- No proof that a protocol is safe.
- No final severity assignment.
- No bounty submission or outcome claim.
- No exploit automation.
- No live-chain operation by default.
- No handling of private keys, seed phrases, or production credentials.

## Default Operating Rule

If a request requires secrets, live-chain execution, exploit automation,
unreviewed network access, or a security conclusion that the artifacts do not
support, it is out of scope.
