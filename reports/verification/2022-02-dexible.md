## Attacker path

Call selfSwap with attacker-controlled target so router uses pre-approved user tokens.

## Invariant broken

Router only forwards user-approved tokens to user-intended destinations.

## Victim impact

Approximately $2M drained across multiple users with active token approvals.

**Loss check:** Victim wallet token balance < pre-attack balance for previously approved tokens.

## Root cause

Router did not validate the swap target, so any address could be invoked with the user's pre-approval still active.

**Protocol assumption that failed:** Assumed selfSwap target was always a vetted DEX adapter.
