## Attacker path

Call exercise with multiple option lots so loop reuses single msg.value as collateral for each.

## Invariant broken

Each exercised option lot is collateralized by its own ETH payment.

## Victim impact

Approximately $370k of collateral drained from ETH put vaults.

**Loss check:** Opyn vault collateral balance < pre-attack balance by the over-exercised amount.

## Root cause

Loop over options used the single msg.value as collateral for each iteration instead of dividing it.

**Protocol assumption that failed:** Assumed each option in the array independently bore its own collateral payment.
