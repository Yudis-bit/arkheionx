## Notes

- `Archival-RPC blocked` is **not** a PoC defect. It records that the public RPC lacks the historical state needed to fork at the declared block. See [`docs/FORK_VERIFICATION.md`](../docs/FORK_VERIFICATION.md).
- `Legacy slug retained` flags entries whose registry `id` stayed the same after a Phase 6A protocol/category reclassification, to keep file paths stable. The current metadata is the source of truth.
- This dashboard is a static snapshot of the registry at the current commit. Re-run the generator after every metadata or verification change.
