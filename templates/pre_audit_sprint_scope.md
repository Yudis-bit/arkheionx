# Arkheionx Pre-Audit Sprint Scope

Paid Arkheionx work is a readiness engagement, not a formal audit.

## Objective

Prepare the authorized repository for a stronger formal audit, contest, or bug
bounty readiness review by turning readiness gaps into a remediation roadmap and
issue plan.

## Deliverables

- Pre-Audit Report.
- SARIF output when scoped.
- GitHub Issue Plan.
- Remediation Roadmap.
- Contest Readiness Report when scoped.
- Suggested invariant/test plan.
- 60-90 minute walkthrough.
- Optional follow-up calibration pass if scoped.

## Assumptions

- Client provides build and test instructions.
- Client confirms repository authorization.
- Client provides known limitations that are safe to share.
- Arkheionx uses local/static analysis and human-guided readiness review.

## Exclusions

- Formal audit sign-off.
- Security guarantee.
- Bug bounty guarantee.
- Exploit development.
- Emergency incident response.
- Live-chain testing or deployed-contract scanning.

## Safety Boundaries

Do not provide private keys, mnemonics, RPC secrets, API tokens, or unpatched
vulnerability details in public channels.

## Client Responsibilities

- Provide repository access or archive.
- Provide build/test commands.
- Identify primary concerns and timeline.
- Review deliverables and own remediation decisions.

## Output Format

Markdown reports, JSON/SARIF artifacts when scoped, and GitHub-native issue
plan output.

## Payment Note

Fee, payment schedule, and out-of-scope rates to be filled during scoping.

## Disclaimer

This engagement is not a formal audit, security certification, or guarantee of
vulnerability absence. Findings are readiness signals and review
recommendations.
