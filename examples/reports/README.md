# Example Reports Boundary

This directory contains tracked sample reports and expected output examples generated from local fixtures.

These files help reviewers understand output shape, regression behavior, SARIF formatting, issue-plan structure, and Markdown report layout. They are safe to inspect, but they are not audit reports and not claims of live exploitable targets.

Treat every issue, gap, or candidate in these files as review context only. Human validation, local reproduction, and protocol-specific judgment are still required.
