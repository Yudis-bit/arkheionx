# Sponsor Prospectus

This page is for people or organizations considering funding Arkheionx Vault.
It explains what sponsorship buys, what it does not buy, and what public
progress should look like.

## Funding Thesis

Most exploit PoC collections optimize for volume. Arkheionx Vault optimizes for
evidence quality:

- pinned fork blocks,
- documented root cause,
- broken invariant,
- assertion families,
- honest verification status,
- public reports generated from metadata.

Sponsorship funds the slow parts that make the archive useful: assertion
hardening, archival verification, case-study writing, and maintenance.

## Why Sponsor

Good sponsor fits:

- Protocol security teams that want better public learning material.
- Tooling companies that benefit from better Foundry-based examples.
- Auditor communities that need reproducible training cases.
- Education programs teaching DeFi security.
- Individuals who want more high-quality public incident analysis.

Poor sponsor fits:

- Anyone looking for live-target exploitation.
- Anyone trying to influence incident classification or severity.
- Anyone seeking an endorsement or audit badge.
- Anyone asking to suppress public technical analysis.

## Sponsor Packages

| Package | Monthly amount | Public output target |
|---|---:|---|
| Maintenance | USD 100 | Link repair, docs cleanup, issue triage |
| Assertion Lane | USD 500 | One weak PoC hardening attempt per month |
| Verification Lane | USD 1,000 | One archival verification attempt per month when RPC access is available |
| Case Study Lane | USD 1,500 | One long-form case-study draft per quarter |
| Research Lane | USD 3,000+ | A named public workstream with monthly progress notes |

Output targets are not guarantees of successful verification. Some incidents
fail because archival state is unavailable, source material is incomplete, or
the PoC itself needs deeper repair. Failed attempts should still produce public
notes so the work is accountable.

## Sponsor Recognition

Optional recognition:

- Sponsor name or handle in a future sponsors section.
- Acknowledgement in funded release notes.
- Acknowledgement in a funded case study.

Recognition wording should be factual:

> This verification pass was funded by <sponsor>.

Recognition wording should not imply:

- audit completion,
- protocol safety,
- partnership,
- endorsement,
- privileged influence over research.

## Suggested First Ask

The cleanest first sponsorship ask:

> Fund one Assertion Lane month: harden one weak historical PoC, regenerate the
> quality matrix, and publish a short progress note.

This is small enough to deliver, visible enough to evaluate, and aligned with
the archive's current bottleneck.

## Progress Metrics

Monthly sponsor update should include:

- weak entries remaining,
- assertion-hardened entries,
- L4 verification reports added,
- public-RPC smoke attempts,
- case-study drafts published,
- known blockers.

Metrics must come from generated reports where possible.
