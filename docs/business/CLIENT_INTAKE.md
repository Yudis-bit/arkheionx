# Client Intake

Use [`../../templates/client_intake.md`](../../templates/client_intake.md) for
paid readiness inquiries.

Paid Arkheionx work is a readiness engagement, not a formal audit.

## Information Needed

- Project name.
- Repository URL or transfer method.
- Whether the repository is public or private.
- Protocol type and chain/ecosystem.
- Audit, contest, or bug bounty timeline.
- Primary concern.
- Build and test commands.
- Known limitations.
- Desired deliverables.

## Authorization

The requester must confirm they own the repository or are authorized to submit
it for evaluation.

Do not include:

- private keys;
- mnemonics;
- RPC secrets;
- API tokens;
- private vulnerability details in public channels;
- unauthorized target information.

## Best First Message

```text
I am requesting Arkheionx readiness support for an authorized repository.
Service of interest:
Repository type:
Timeline:
Primary concern:
Preferred deliverables:
Authorization confirmed:
```
