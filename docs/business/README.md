# Business Docs Boundary

This directory contains optional service, sponsorship, and paid-work boundary material.

It is not the core ArkheionX technical documentation. The public technical entry point is [`../README.md`](../README.md), and the repository structure overview is [`../REPOSITORY_STRUCTURE.md`](../REPOSITORY_STRUCTURE.md).

These files must not claim that ArkheionX is a formal audit, a security certification, a vulnerability guarantee, or a bounty guarantee. Any paid-work language should stay subordinate to the project boundary: ArkheionX is local-first review infrastructure that produces review context for human reviewers.
