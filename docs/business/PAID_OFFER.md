# Paid Offer

Arkheionx paid services help DeFi teams prepare authorized repositories before
formal audits, contests, or bug bounty launches by turning readiness gaps into
reports, issue plans, and remediation workflows.

Paid Arkheionx work is a readiness engagement, not a formal audit.

## What Is Free

- Local CLI scanner.
- GitHub Action.
- Markdown, JSON, SARIF, baseline, diff, issue-plan, and delivery artifact
  generation.
- Security Memory Graph and local knowledge search.
- Public demo fixtures and case studies.
- Feedback templates and rule calibration backlog.

## What Is Paid

Paid work is human-guided readiness support around the open-source outputs:

- manual review of generated reports and evidence;
- prioritization of readiness gaps;
- issue-plan cleanup and owner-ready task framing;
- remediation roadmap planning;
- contest/scope readiness guidance;
- GitHub Action setup support;
- rule calibration feedback when scan output is noisy.

requested.

## Required Safety Boundaries

- Only submit repositories you own or are authorized to evaluate.
- Do not share private keys, mnemonics, RPC secrets, API tokens, or production
  credentials.
- Do not disclose unpatched vulnerability details in public issues or public
  intake forms.
- Use responsible disclosure for bounty or active vulnerability information.
- Arkheionx findings are readiness signals and review recommendations, not
  vulnerability confirmations.

## What Paid Work Does Not Include

- Formal audit sign-off.
- Security guarantee.
- Bug bounty guarantee.
- Exploit discovery guarantee.
- Exploit payload development.
- Live-chain testing.
- Deployed-contract scanning.
- Emergency incident response.
- Legal, compliance, or security certification.
