# Fix First

The Fix First section ranks the readiness gaps that are most useful to address
early in a pre-audit sprint.

Ranking considers:

- priority and readiness-blocking impact;
- confidence;
- local evidence volume;
- affected files;
- whether suggested tests or invariants are available.

Fix First wording is intentionally cautious. It says why a gap is worth
prioritizing for audit preparation; it does not claim exploitability or
confirmed vulnerability status.

Each row includes:

- finding ID;
- title;
- rule family;
- why it was ranked;
- recommended next action.

Use Fix First to start remediation planning, then confirm scope and test design
with human review.
