# Launch Plan

This public-safe checklist exists only to keep release communication aligned
with repository evidence. It is not an announcement draft and does not claim
that a release has been published.

## Default

Stay quiet unless there is a technical artifact worth pointing to: a tagged
release, fixture-harness update, public demo improvement, documentation update,
or generated report that exists in the repository.

## Required Checks

- Match every claim to a repository artifact.
- Avoid adoption, customer, partner, or funding claims unless public evidence is
  already present.
- Avoid audit-result, safety-proof, severity, or bounty-outcome claims.
- Keep defensive framing: local review context, authorized repositories, human
  review required.
- Link to technical docs instead of broad promotional copy.

## Safe Technical Topics

- Fixture benchmark harness behavior.
- Deterministic source fingerprints.
- Snapshot drift checks.
- Local/offline operation.
- CLI validation and documentation updates.
