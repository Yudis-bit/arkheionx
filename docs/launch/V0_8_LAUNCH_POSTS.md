# Public Demo Notes

This file is retained for compatibility with the public demo validation tests.
It is a technical demo-note fixture, not an announcement draft and not evidence
of a published release.

## Demo Summary

ArkheionX can be evaluated locally with repository fixtures and generated
sample artifacts. The demo path is intentionally defensive and static:

- no RPC;
- no deployed-contract scanning;
- no private keys or seed phrases;
- no live-chain execution;
- no exploit automation;
- no audit claim;
- no automatic report submission.

## Public Copy Boundary

Acceptable public copy may say that the demo produces local review context such
as Markdown, JSON, SARIF, issue-plan, and remediation-roadmap artifacts.

Public copy must not claim users, customers, partners, external validation,
audit outcomes, safety guarantees, bounty outcomes, or automated vulnerability
confirmation unless the repository contains explicit public evidence for that
claim.
