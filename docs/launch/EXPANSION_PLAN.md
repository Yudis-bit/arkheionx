# Expansion Plan

This document records optional archive-growth quality gates for the historical
PoC corpus. It is not a release schedule, adoption claim, or promise of future
coverage.

ArkheionX itself remains local-first by default. Any historical fork replay or
archival RPC work described here is outside the default ArkheionX review
workflow and must be performed only on authorized, lawful material.

## Principles

- Quality gates matter more than corpus size.
- Public counts must match repository metadata and generated reports.
- Historical replay evidence must stay separate from local review guidance.
- Expansion must not add live-chain operation, exploit automation, or
  unauthorized target workflows.

## Milestone Model

Milestones are quality bars, not dates:

- M1: a small verified historical set with complete metadata and reports.
- M2: broader taxonomy coverage with repeatable review process.
- M3: category-level representative coverage and drift checks.
- M4: cross-VM coverage only when methodology and evidence support it.
- M5: sustained maintenance with public methodology and review discipline.

Partial completion does not count as milestone completion.

## Anti-Goals

- Counting template or educational entries as verified historical evidence.
- Marking anything verified without supporting artifacts.
- Creating packages that target current production systems.
- Comparing the repository to named firms, programs, or other archives by way
  of superiority claims.
- Treating local review output as an audit, safety proof, or vulnerability
  confirmation.

## Current-State Rule

The authoritative state is the repository metadata and generated reports. If
those artifacts do not support a claim, the claim must not be made.
