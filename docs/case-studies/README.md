# ArkheionX Case Studies

This folder contains case studies and case-study templates.

Case studies are review evidence records, not marketing claims.

## Types

- Fixture case studies: synthetic or toy workflows used for examples and regression confidence.
- Review workflow case studies: real review workflows where ArkheionX helped map context or evidence.
- Accepted external findings: only when acceptance is proven and linked or otherwise recorded with permission.

## Required boundary

Every case study should say what ArkheionX helped clarify and what it did not decide.

ArkheionX does not replace auditors, confirm severity automatically, or prove a protocol safe.
