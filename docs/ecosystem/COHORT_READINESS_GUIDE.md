# Cohort Readiness Guide

Use this guide when Arkheionx is applied to an audit-prep cohort, accelerator,
grant batch, or builder support program.

## Suggested Cohort Flow

1. Collect authorization and intake from each participating repository.
2. Confirm build/test instructions and expected report artifacts.
3. Run Arkheionx locally for each authorized repository.
4. Share private repo-level outputs with the corresponding team.
5. Create an anonymized common-gap summary for the operator.
6. Hold a walkthrough focused on recurring blockers and next steps.

## Cohort-Level Themes

Common themes to track:

- Missing invariant tests.
- Oracle assumption gaps.
- Admin boundary documentation gaps.
- Reentrancy/value-flow test gaps.
- Reward accounting conservation gaps.
- Contest scope and researcher onboarding gaps.

## Operator Outputs

- Readiness distribution.
- Rule-family heatmap.
- Top recurring blockers.
- Suggested shared workshops.
- GitHub Action setup recommendations.

## Boundaries

Do not compare teams publicly, publish private details, or imply that a score
certifies readiness. The goal is preparation and prioritization.
