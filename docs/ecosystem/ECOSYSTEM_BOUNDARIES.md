# Ecosystem Boundaries

Arkheionx ecosystem work must preserve trust across participating builders,
operators, and reviewers.

## Allowed

- Multi-repo readiness summaries for authorized repositories.
- Anonymized common-gap reporting.
- Repo-by-repo private readiness tables.
- GitHub Action setup recommendations.
- Rule calibration notes.
- Defensive testing and documentation recommendations.

## Not Allowed

- Unauthorized repository scanning.
- Remote cloning without explicit authorization.
- RPC calls, live-chain scanning, or transaction execution.
- Deployed-contract attack analysis.
- Exploit payload generation.
- Private key, mnemonic, API token, or secret handling.
- Public disclosure of unpatched vulnerability details.
- Public naming without permission.

## Claim Boundaries

Do not claim:

- formal audit coverage;
- ecosystem certification;
- audit certification;
- security guarantees;
- bounty guarantees;
- official ecosystem endorsement;
- partnership with chains, audit firms, contest platforms, or bounty platforms;
- customer adoption without committed public evidence.

Use:

- ecosystem readiness;
- multi-repo readiness;
- authorized repositories;
- anonymized gap summary;
- common readiness gaps;
- audit preparation;
- contest preparation;
- local/static analysis.
