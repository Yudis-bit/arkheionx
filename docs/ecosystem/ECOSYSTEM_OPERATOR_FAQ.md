# Ecosystem Operator FAQ

## Is this a formal audit for each repository?

No. Arkheionx Ecosystem Pack is readiness support, not a formal audit or
certification.

## Can private repositories be included?

Only with authorization from the repository owner or maintainer. Public
summaries should use aliases unless explicit public permission exists.

## Does Arkheionx scan deployed contracts?

No. The workflow is local/static repository analysis. It does not add RPC,
live-chain calls, transaction execution, or deployed-contract scanning.

## Can summaries name participating teams?

Only with explicit public permission. The default is anonymized reporting.

## What if a report surfaces sensitive vulnerability details?

Do not publish them. Move discussion to the agreed private disclosure path and
follow the relevant responsible disclosure policy.

## What should an operator receive?

The operator should receive aggregate readiness themes, anonymized repo aliases,
common gaps, and recommended ecosystem actions. Individual private reports
should only go to authorized recipients.
