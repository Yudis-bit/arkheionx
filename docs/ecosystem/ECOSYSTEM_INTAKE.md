# Ecosystem Intake

Use [`../../templates/ecosystem_intake.md`](../../templates/ecosystem_intake.md)
before starting a multi-repo readiness pilot.

## Required Information

- Ecosystem or operator name.
- Purpose of the readiness pilot.
- Number of repositories.
- Repository aliases.
- Public/private status for each repository.
- Authorization confirmation for each repository.
- Audit, contest, or bug bounty timeline.
- Preferred deliverables.
- Anonymization preference.
- Permission for public case study, if any.

## Authorization

Every repository must be owned by, maintained by, or explicitly authorized by
the requester.

## Information To Avoid

Do not include private keys, mnemonics, RPC secrets, API tokens, production
credentials, customer data, private code snippets, or unpatched vulnerability
details in public forms or public summaries.
