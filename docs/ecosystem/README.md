# Ecosystem Docs Boundary

This directory contains ecosystem pilot, cohort-readiness, and validation workflow material.

It is useful for conversations with protocol teams, auditors, and grant reviewers, but it is not an endorsement claim and not a formal grant pathway. Feedback from ecosystem review should be treated as product guidance unless there is explicit written approval to claim otherwise.

Use these docs to structure responsible pilots, external reviewer feedback, and case-study intake.
