# Anonymized Reporting

Anonymized reporting helps ecosystem operators understand common readiness gaps
without exposing private repository details.

## Default Rule

Use aliases by default:

- Repo Alpha
- Repo Beta
- Repo Gamma
- Repo Delta
- Repo Epsilon

Do not use real project names unless explicit public permission exists.

## What Can Be Shared

- Score band.
- Protocol type.
- Rule-family counts.
- Recurring readiness themes.
- Suggested defensive tests.
- GitHub Action setup recommendations.

## What Should Be Redacted

- Private code snippets.
- Contract names that identify a private project.
- Unpatched vulnerability details.
- Deployment addresses.
- Secret names, tokens, or credential material.
- Private audit or bounty details.

## Allowed Claim

“This is an anonymized readiness summary generated from authorized repository
reports.”

## Disallowed Claim

Do not claim ecosystem endorsement, customer adoption, security certification,
or audit certification unless explicit public evidence exists.
