# Proposal Template

Use this template for scoped commercial work. It keeps offers concrete and
prevents the engagement from drifting into live-target or audit-signoff work.

```text
Proposal: <engagement name>

Prepared for:
Prepared by: Yudistira Putra / arkheionx
Date:

## 1. Scope

This engagement covers:
- <historical incident / PoC / workshop topic>
- <chain / VM>
- <public references>

This engagement does not cover:
- live-target exploitation
- scanner or drain tooling
- private-key, RPC-key, or credential handling
- full smart-contract audit signoff
- guaranteed bounty or contest outcome

## 2. Deliverables

- <deliverable 1>
- <deliverable 2>
- <deliverable 3>

## 3. Inputs Needed

- Public post-mortem or authoritative writeup
- Current PoC repository or file, if available
- Target chain and fork block, if known
- Confirmation of historical, patched, or authorized status
- Preferred review format

## 4. Process

1. Intake and source review
2. PoC / metadata / assertion review
3. Draft deliverable
4. Review call or async feedback
5. Final handoff

## 5. Timeline

Estimated duration:
Start date:
Milestones:

## 6. Fee

Fixed fee:
Payment schedule:
Out-of-scope work:

## 7. Safety and Disclosure

All work is defensive and limited to historical, patched, or authorized targets.
Any indication that the target is unpatched or under embargo pauses the work
until the correct disclosure path is confirmed.

## 8. Acceptance

Client:
Maintainer:
Date:
```

## Suggested Fixed-Fee Anchors

| Engagement | Suggested quote |
|---|---:|
| One PoC assertion review memo | USD 300-750 |
| Assertion hardening sprint | USD 750-2,500 |
| Historical reproduction report | USD 2,500-7,500 |
| 90-minute workshop | USD 1,000-1,500 |
| Half-day workshop | USD 2,500-3,500 |
| Monthly research review retainer | USD 2,000-5,000 |

Use lower ranges for pilot customers only when the deliverable can become a
public sample or case-study excerpt.
