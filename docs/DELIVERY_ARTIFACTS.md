# Delivery Artifacts

Arkheionx is GitHub-native: every delivery artifact is a file that can live in
a repository, workflow artifact, pull request, issue, or release.

## Artifact Map

| Artifact | Purpose |
|---|---|
| Pre-audit Markdown report | Full technical readiness report. |
| JSON report | Machine-readable findings, score, evidence, outputs, and metadata. |
| SARIF | GitHub Code Scanning-compatible readiness gaps. |
| Baseline JSON | Compact snapshot for future comparison. |
| Diff report | New, resolved, unchanged, and changed readiness gaps. |
| PR comment | Pull request summary for maintainers. |
| Issue checklist | Copyable Markdown remediation checklist. |
| Issue plan | Structured JSON plan for optional GitHub issue workflow. |
| Launch Report | Client-facing launch readiness report. |
| Sprint Plan | 3/5/7/10 day Pre-Audit Sprint plan. |
| Contest Readiness Report | Scope and researcher onboarding preparation. |
| Executive Summary | Short founder/stakeholder summary. |
| Remediation Roadmap | Phase-based remediation task roadmap. |

## Delivery Principles

- Defensive use only.
- Authorized repositories only.
- No live-chain/RPC behavior.
- No exploit automation.
- No formal audit or security guarantee claims.

## Recommended Bundle

For a paid Launch Report:

- Pre-audit Markdown report.
- JSON report.
- Executive summary.
- Launch Report.
- Remediation roadmap.
- Issue plan.

For a Pre-Audit Sprint:

- Sprint plan.
- Issue checklist.
- Issue plan.
- Baseline and diff artifacts.
- Final readiness summary.

For contest preparation:

- Contest Readiness Report.
- Scope checklist.
- Researcher onboarding checklist.
- Remediation roadmap.
- Known limitations notes.
