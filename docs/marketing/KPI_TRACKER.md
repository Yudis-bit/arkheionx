## Conversion Benchmarks

These are working targets for the first month:

| Metric | Good early signal |
|---|---:|
| Reply rate on personalized outbound | 10-20% |
| Call booking rate from replies | 25-40% |
| Proposal rate from calls | 30-50% |
| Close rate from proposals | 25-50% |
| Qualified inbound from content | 1-3 per week |

If reply rate is below 5%, tighten the target list or improve the first line.
If calls happen but proposals do not, the offer is unclear. If proposals do
not close, reduce scope and sell a smaller starter package.

## Weekly Review Questions

- Which segment produced the best replies?
- Which message produced a call?
- Which post generated qualified inbound?
- Which objection repeated more than twice?
- Which offer should be pushed next week?
- Which public proof asset would make closing easier?

## Revenue Math

Simple first-month path:

```text
80 personalized messages
12 replies
5 calls
3 proposals
1 closed workshop at USD 1,500
1 closed assertion sprint at USD 1,500
3 sponsors at USD 250/month

First-month cash: USD 3,750
Monthly recurring support: USD 750
```

This is not a forecast. It is a control model for deciding whether the channel
is worth repeating.
