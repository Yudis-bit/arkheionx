## Archetype

Arkheionx is a **defensive security memory and pre-audit readiness system**.
It includes the Arkheionx Vault archive, but the public surface should no
longer make the repository look archive-only.

- Security memory preserves historical pattern context.
- Readiness tooling helps authorized repositories prepare for review.
- Reports, issue plans, and feedback workflows stay local/static and
  defensive.

The brand should read as practical, evidence-backed security tooling published
in public, not a hype-driven landing page.

## Tone

- Calm, technical, specific.
- Short paragraphs, concrete claims.
- Every sentence earns its place.
- Severity, dates, block numbers, and chains are stated; adjectives are not.

### Words to avoid

- "world-class", "cutting-edge", "next-generation", "industry-leading"
- "comprehensive" (unless it actually is)
- "robust", "scalable", "unstoppable"
- "elite", "1000x", "military-grade"
- "AI-powered" (unless it literally is)
- "trusted by" (unless it actually is)
- Generic Web3 marketing copy

### Words and patterns to use

- "deterministic"
- "historical"
- "patched"
- "reproducible"
- "fork at block N"
- "root cause: X"
- "see post-mortem at <link>"

## Visual direction

- Dark, archival, restrained.
- Mono and serif typography over display fonts.
- No gratuitous gradients, no animated backgrounds-as-decoration.
- Tables and registries over hero illustrations.

## Boundaries

This brand is **defensive security research**.

- It does not glorify exploits.
- It does not provide live-target attack tooling.
- It does not solicit work using outcomes it has not delivered.
- It does not invent prestige (audits, contests, bounties) it has not earned.

If the repository's actual capability changes, the brand language updates with
it. The brand never runs ahead of the work.

## Commercial language

Commercial pages may offer scoped research work only when the deliverable is
concrete: Launch Reports, Pre-Audit Sprints, Contest Readiness Packs, rule
calibration, assertion hardening, historical reproduction review, root-cause
writing, verification planning, or auditor training.

Use:

- "available for scoped defensive research work"
- "assertion hardening for historical PoCs"
- "training based on public post-mortems"
- "sponsorship funds archive maintenance and verification work"
- "pre-audit readiness review based on generated artifacts"
- "report-quality and rule-calibration support"

Avoid:

- "hire me to audit your protocol" unless a full audit practice is actually
  being offered and evidenced elsewhere.
- "assured bounty outcome", "guaranteed exploit", or anything that prices an
  outcome the maintainer does not control.
- "verified exploit database" while the L4 count is zero.
- Any phrasing that suggests sponsors can influence findings, categories,
  severity, or verification status.
