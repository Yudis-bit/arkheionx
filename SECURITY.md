# Security Policy

## Scope

ArkheionX is local-first security review tooling. The default workflow operates
on local repository files and generated local artifacts.

## Reporting Security Issues

Please open a private GitHub security advisory if available, or contact the
maintainer through GitHub until a dedicated security email is published.

Do not disclose sensitive details publicly before the maintainer has had a
reasonable opportunity to investigate and respond.

## Safety Boundaries

- No exploit automation.
- No live-chain operation by default.
- No secrets required.
- No vulnerability confirmation.
- No audit guarantee.
- No bounty claim.
- Human review required.

## Responsible Use

Use ArkheionX only on repositories you own or are authorized to review. Do not
point local workflows at live targets, private credentials, or third-party
systems without explicit authorization and a reviewed design.
